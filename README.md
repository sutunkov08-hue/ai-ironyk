# ai-ironyk

Сайт-чат с ИИ-ассистентом **ai-ironyk**. Весь сайт — один файл `index.html`, бэкенд не нужен: сообщения ходят через публичный MQTT-брокер (`broker.emqx.io`) по WebSocket.

## Запуск локально

Просто откройте `index.html` в браузере — или поднимите любой статический сервер:

```bash
npx serve .
```

## Публикация (GitHub Pages)

1. Settings → Pages → Source: **Deploy from a branch**
2. Branch: `main`, папка `/ (root)` → Save
3. Сайт будет доступен по адресу `https://sutunkov08-hue.github.io/ai-ironyk/`

## Вход

- Код `9988` — панель ИИ: список входящих чатов, уведомления (звук, тост, браузерные push) и ответы от имени ai-ironyk.
- Любой другой код — гостевой чат: гость вводит ник и общается с ai-ironyk. Когда ИИ «думает», гость видит индикатор «Генерируется ответ…».

## Возможности

- Несколько собеседников одновременно: у каждого гостя своя сессия, панель ИИ показывает их списком с непрочитанными.
- История переписки синхронизируется при переподключении.
- Индикатор генерации ответа с меняющимися статусами.

## Настройка приватного канала

Канал задан константой `ROOM_ID` в начале `<script>` в `index.html`. Поменяйте её на своё случайное значение, чтобы переписка не пересекалась с чужими и была недоступна тем, кто знает текущее значение.
