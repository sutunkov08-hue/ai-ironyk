# ai-ironyk

Чат с ИИ-ассистентом **ai-ironyk**. Весь сайт — один файл `index.html`, бэкенд не нужен: сообщения ходят через публичный MQTT-брокер (`broker.emqx.io`) по WebSocket.

## Запуск локально

Просто откройте `index.html` в браузере — или поднимите любой статический сервер:

```bash
npx serve .
```

## Публикация (GitHub Pages)

1. Settings → Pages → Source: **Deploy from a branch**
2. Branch: `main`, папка `/ (root)` → Save
3. Сайт будет доступен по адресу `https://sutunkov08-hue.github.io/ai-ironyk/`

## Вход

Вход выполняется по коду доступа. Если кода нет — введите любое число, и откроется чат: собеседник указывает ник и общается с ai-ironyk.

## Возможности

- Ники собеседников.
- Два формата сообщений: обычный текст и «Скрипт» — тёмный блок кода с кнопкой «Копировать».
- ai-ironyk сам оформляет код и скрипты: когда в ответе есть блок кода, он отображается отдельным тёмным блоком с кнопкой «Копировать».
- Отправка файлов и изображений (картинки показываются прямо в чате, фото можно слать с обеих сторон).
- ai-ironyk видит присланные фото: описание изображения формируется локально в браузере (модель компьютерного зрения загружается с CDN при первом фото), без API-ключей.
- Многострочный ввод без ограничений по длине (Enter — отправить, Shift+Enter — новая строка).
- Индикатор генерации ответа с эффектом постепенного набора текста.
- История переписки синхронизируется при переподключении.

## Настройка канала

Канал задан константой `ROOM_ID` в начале `<script>` в `index.html`. Поменяйте её на своё случайное значение, чтобы переписка не пересекалась с другими.
